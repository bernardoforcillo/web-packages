# Security Policy

## Supported versions

Security fixes are released only for the latest published version of each
package (`@bernardoforcillo/vite-seo` and the `vite-serve` crate).

## Reporting a vulnerability

Please do not open a public issue for security problems.

Email **bernardoforcillo@gmail.com** with:

- the affected package and version;
- a description of the issue and its impact;
- steps to reproduce (a minimal snippet or repository, if possible).

If GitHub Security Advisories are enabled on the repository, you can instead
use private reporting from the **Security** tab.

## Response times

- Acknowledgement within 5 business days.
- Assessment and fix plan within 30 days.
- The vulnerability is disclosed publicly after a fix is released, with credit
  to the reporter if desired.
